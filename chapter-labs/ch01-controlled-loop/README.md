# Chapter 1 Lab — Controlled Engineering Loop

**Starting state:** `book-start`

**Objective:** compare an underspecified AI coding task with a controlled engineering workflow.

## Deliverables
- `uncontrolled-observations.md`
- `controlled-plan.md`
- `verification-evidence.md`
- `final-review.md`

## Workflow
1. Run one intentionally underspecified task and record files inspected, files changed, tests run, assumptions, and missing evidence.
2. Reset to the known-good state.
3. Repeat the task using Explore → Plan → Implement → Verify.
4. Record the targeted test, affected regression test, final diff, and authority Claude actually needed.

## Verification
The controlled run should be easier to review, better scoped, and supported by explicit evidence rather than the agent's completion claim.
